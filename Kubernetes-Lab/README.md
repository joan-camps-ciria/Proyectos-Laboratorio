## 🛠 Requisitos Previos

Antes de empezar, asegúrate de tener instalado:
*   [Node.js](https://nodejs.org) (Versión 18 o superior)
*   Un editor de código como [VS Code](https://visualstudio.com)

---

## Paso 1: Instalación

Abre tu terminal y ejecuta el siguiente comando para instalar las dependencias:

```bash
npm install mi-paquete-especial
```

> 💡 **Nota:** Si estás en Linux o macOS, es posible que necesites usar `sudo` antes del comando si experimentas problemas de permisos.

---

## Paso 2: Configuración Inicial

Crea un archivo llamado `config.js` y añade el siguiente bloque de código. Verás cómo Git resalta la sintaxis automáticamente:

```javascript
// Configuración del entorno
const config = {
    apiKey: "TU_API_KEY_AQUI",
    modoDesarrollo: true,
    puerto: 8080
};

export default config;
```

---

## 💬 Preguntas Frecuentes

<details>
<summary><b>¿Qué hago si obtengo un error de puerto ocupado?</b></summary>
Puedes cambiar el puerto `8080` en el archivo <code>config.js</code> por cualquier otro número libre, como el `3000`.
</details>

<details>
<summary><b>¿Este tutorial sirve para producción?</b></summary>
No, está diseñado exclusivamente para entornos de desarrollo local.
</details>
